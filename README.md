# TopDownSurvivor 俯视角动作生存游戏

一款类似《吸血鬼幸存者》的俯视角生存闯关游戏。玩家在场上移动躲避，自动攻击消灭从四周不断涌来的敌人，尽可能存活更久。项目重点在于**代码架构**与**性能优化**。

## 技术亮点

- **对象池（Object Pool）**：预创建 + 复用子弹，避免频繁 `Instantiate`/`Destroy` 导致的 GC 卡顿（性能优化核心）
- **敌人追击 AI（Seek）**：通过向量相减 + 归一化实现追踪行为
- **刷怪系统**：使用协程（Coroutine）定时从玩家四周生成敌人
- **自动攻击**：遍历敌人查找最近目标（线性求最小值算法）
- **事件系统（EventBus）**：泛型类型安全事件总线，解耦模块间通信
- **单例管理器（Singleton）**：统一的 MonoBehaviour 单例基类

## 目录结构

```
Assets/
├── Scripts/
│   ├── Core/       # 核心框架（Singleton / EventBus / GameManager / ObjectPool）
│   ├── Player/     # 玩家（移动 / 自动攻击）
│   ├── Enemies/    # 敌人（追击 AI / 刷怪器）
│   └── Weapons/    # 武器（子弹）
├── Editor/         # 编辑器工具（一键搭建场景）
├── Prefabs/        # 预制体
├── Sprites/        # 占位精灵
└── Scenes/         # 场景
```

## 技术栈

- Unity **2022.3.62f3c1**（2D Built-In Render Pipeline）
- C#

## 如何运行

1. 使用 Unity Hub 打开项目（编辑器版本 2022.3.62f3c1）
2. 打开场景 `Assets/Scenes/SampleScene`
3. 点击菜单 `Tools → TopDownSurvivor → Setup Scene` 一键搭建场景（自动生成玩家、敌人、相机）
4. 点击 Play，使用 WASD 移动
